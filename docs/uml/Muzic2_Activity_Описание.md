# Диаграмма активности Muzic2 — разбор и текст для диплома

**Рисунок:** диаграмма активности действий пользователя и администратора веб-сервиса Muzic2.

**Файлы для картинки:**
- `Muzic2_Activity_User_RU.puml` — полные подписи
- `Muzic2_Activity_User_RU_Readable.puml` — **крупный шрифт** (для Word, лучше видно)

**Как получить PNG:** https://www.plantuml.com/plantuml/uml/ → вставить файл → Submit → скачать PNG.

---

## 1. Общая структура

```
        [НАЧАЛО]
            |
    Открыть Muzic2
            |
      <Кто работает?>
       /            \
ПОЛЬЗОВАТЕЛЬ    АДМИНИСТРАТОР
      |              |
  (цикл работы)   (админ-панель)
      |              |
   [КОНЕЦ]        [КОНЕЦ]
```

Два независимых сценария: обычный пользователь слушает музыку; администратор управляет каталогом.

## 2. Ветка «Пользователь»

### 2.1. Раздел «Вход»

| Шаг | Действие |
|-----|----------|
| 1 | Открыть сайт Muzic2 |
| 2 | Если не авторизован — ввести логин и пароль, нажать «Войти» |
| 3 | При отсутствии аккаунта — регистрация |
| 4 | При ошибке — сообщение, вход прекращается |
| 5 | После входа — главная страница, меню: **Главная**, **Поиск**, **Моя музыка** |

### 2.2. Цикл «Выбрать раздел»

Пользователь многократно выбирает раздел, пока пользуется сервисом.

#### А) Главная

- Просмотр подборок треков и альбомов, списка артистов.
- **Пульс** — персональный поток музыки.
- **Продолжить слушать** — недавно прослушанное.
- **Лайк** на карточке — добавить/убрать трек из любимых.
- **Открыть карточку** — переход к треку, альбому или артисту.

#### Б) Поиск

- Ввести запрос.
- Просмотреть треки, альбомы, артистов.
- Выбрать результат (далее — прослушивание).

#### В) Моя музыка

- Любимые треки, любимые альбомы, свои плейлисты.
- **Создать плейлист:** название, треки, обложка (или автоматическая), сохранить.
- **Открыть плейлист:** список треков, включить трек.
- **Удалить плейлист:** системный «Любимые треки» удалить нельзя; остальные — с подтверждением.
- **Лайк альбома** — в любимые или убрать.

#### Г) Альбом

- Обложка и список треков.
- Слушать альбом целиком или один трек.
- Добавить альбом в любимые.

#### Д) Артист

- Дискография, популярные треки.
- Переход на альбом, прослушивание треков артиста.

#### Е) Меню трека

- ПКМ или «три точки».
- Пункты: **в любимое**, **в плейлист**, **играть**.

#### Ж) Выйти

- Выход из аккаунта → конец сценария.

### 2.3. Блок «Прослушивание» (после любого раздела)

Выполняется при включении музыки:

| Управление | Действие |
|------------|----------|
| Пауза | Остановить / продолжить |
| Следующий | Следующий трек в очереди |
| Предыдущий | Предыдущий трек |
| Перемотка | Изменить место в треке |
| Очередь | Открыть список, выбрать трек |
| Текст песни | Синхронный текст, караоке |
| Лайк | Отметить трек сердцем |

Цикл: пока пользователь в сервисе — снова «Выбрать раздел». Иначе — закрыть браузер, **конец**.

## 3. Ветка «Администратор»

### 3.1. Вход в админ-панель

- Открыть `/public/admin/`.
- Войти под учётной записью администратора.

### 3.2. Цикл работы в панели

Выбор вкладки: **Артисты** | **Альбомы** | **Треки**.

#### Вкладка «Артисты»

| Действие | Что делает админ |
|----------|------------------|
| Просмотр | Список артистов, поиск по имени |
| Добавить | Имя, обложка, описание → сохранить |
| Изменить | Карточка артиста → правка → сохранить |
| Удалить | Подтверждение удаления |

#### Вкладка «Альбомы»

| Действие | Что делает админ |
|----------|------------------|
| Просмотр | Список альбомов, поиск |
| Добавить | Альбом, артист, обложка → сохранить |
| Изменить | Название, артист, тип, обложка |
| Удалить | Подтверждение удаления |

#### Вкладка «Треки»

| Действие | Что делает админ |
|----------|------------------|
| Просмотр | Список, поиск, фильтр по альбому |
| Добавить | Название, артист, альбом, файл, обложка |
| Изменить | Поля трека (в т.ч. видео, explicit) |
| Удалить | Подтверждение удаления |

**Дополнительно:** при необходимости — загрузить файл обложки.

Пока админ в панели — повтор выбора вкладки. Затем закрыть панель → **конец**.

## 4. Текст для пояснительной записки (можно вставить как есть)

> На рисунке X представлена диаграмма активности веб-сервиса Muzic2. После открытия сервиса поток делится на два варианта: действия зарегистрированного пользователя и действия администратора.
>
> Пользователь проходит авторизацию, получает доступ к разделам «Главная», «Поиск» и «Моя музыка», просматривает каталог, формирует плейлисты, отмечает любимые треки и альбомы, открывает страницы альбомов и артистов. Воспроизведение музыки сопровождается работой встроенного плеера: управление очередью, пауза, перемотка, отображение текста песни.
>
> Администратор работает в отдельной панели управления контентом: ведёт справочник артистов, альбомов и треков (добавление, изменение, удаление, загрузка обложек). Таким образом, диаграмма отражает полный пользовательский интерфейс сервиса без описания серверной реализации.
