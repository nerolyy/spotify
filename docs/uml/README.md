## Главные файлы (полные)

| Файл | Назначение |
|------|------------|
| **`Muzic2_Activity_Full.puml`** | Полная диаграмма активности (латиница — **без ошибок** на plantuml.com) |
| **`Muzic2_Activity_Full_RU.puml`** | То же на русском (если редактор поддерживает UTF-8) |

| № | Имя в файле | Тип | Содержание |

| 2 | `Muzic2_Classes` | Классы (концептуальная модель) | User, Track, Playlist, Like… |
| 3 | `Muzic2_Components` | Компоненты | app.js, API, админка, MySQL |
| 4 | `Muzic2_Deployment` | Развёртывание | Браузер — MAMP — MySQL |
| 5 | `Muzic2_Sequence_Auth` | Последовательность | Вход |
| 6 | `Muzic2_Sequence_MyMusic` | Последовательность | «Моя музыка» |
| 7 | `Muzic2_Sequence_CreatePlaylist` | Последовательность | Создание плейлиста |
| 8 | `Muzic2_Activity_Pulse` | Активность | «Пульс» |
| 9 | `Muzic2_State_Session` | Состояния | Сессия |
| 10 | `Muzic2_ER` | ER (сущность–связь) | Таблицы MySQL |

## Как получить картинки для диплома

### Вариант 1 — онлайн
1. Откройте https://www.plantuml.com/plantuml/uml/
2. Скопируйте один блок от `@startuml Имя` до `@enduml`.
3. Скачайте PNG/SVG.

### Вариант 2 — VS Code
1. Расширение **PlantUML**.
2. Откройте `Muzic2_UML.puml` → `Alt+D` (превью).

### Вариант 3 — draw.io
Импорт → PlantUML → вставить фрагмент.

- *Рисунок X+1 — Концептуальная диаграмма классов*
- *Рисунок X+2 — Диаграмма компонентов*
- *Рисунок X+3 — Диаграмма развёртывания*
- *Рисунок X+4 — Диаграмма последовательности: авторизация*

ER-диаграмму БД можно взять отдельным рисунком из MySQL Workbench / уже готовой схемы `muzic2`.

### Ошибка Syntax Error на plantuml.com

1. Вставляйте **только один** блок: от `@startuml` до `@enduml` (не весь файл с админкой).
2. Не используйте `skinparam activity { a; b; }` в одну строку — в старом движке это ломает парсер.
3. Не используйте `**жирный**` и символы `→ ♥ ⋮` в подписях.
4. Если русский текст даёт ошибку — откройте **`Muzic2_Activity_Full.puml`** (латиница, полный смысл тот же).

### Диаграмма активности (что внутри)

1. **Muzic2_Activity_Full** — весь пользовательский сценарий:
   - `start` → инициализация → вход/регистрация
   - Главная (Пульс, карточки, continue listening)
   - Поиск, Моя музыка (плейлисты CRUD, лайки)
   - SPA альбом / артист
   - Плеер (очередь, караоке, лайки)
   - `stop` при выходе / закрытии
2. **Muzic2_Activity_Admin** — админка: артисты, альбомы, треки (create/update/delete)
